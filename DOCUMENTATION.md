# KNEX Exchange System Documentation

## Overview
KNEX Exchange is a high-performance synthetic options trading platform designed for rapid execution and automated growth.

## Core Features
- **Synthetic Price Feeds:** Real-time tick indexes (e.g., MFLOW) running 24/7.
- **Rapid Options:** 10-second to multi-minute trade expirations with up to 95% yield.
- **Admin Console:** Centralized control for user management, risk controls, P2P oversight, and automated growth bots (Telegram, WhatsApp, Facebook).
- **Marketing Hub:** Integrated studio for generating high-resolution posters, social media campaign management, and performance tracking.

## Administration Portal
The Admin Console manages:
- **User Management:** View/edit user balances, ban/unban users.
- **Transaction Oversight:** Process deposits and withdrawals.
- **Bot Management:** Configure automated marketing and outreach via Telegram, WhatsApp, and Facebook.
- **Marketing & Posters:** Use the integrated studio to generate social media materials and manage campaign schedules.

## Configuration
To run the system, create a `.env` file in the root directory with the following variables:
- `ADMIN_USERNAME`: Admin username
- `ADMIN_PASSWORD`: Admin password
- `ADMIN_KEY`: Security key for Super Admin access
- `GEMINI_API_KEY`: API key for AI-powered features
